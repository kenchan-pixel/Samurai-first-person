# UI Polish Pass

Goal: improve hierarchy, readability, touch-zone feedback, and visual coherence of the existing mobile-first HUD without changing gameplay logic.

Scope:
- clearer top HUD grouping and health readability;
- stronger combat prompt and direction cue hierarchy;
- subtler but more legible guard-zone affordances;
- refined start/result modal presentation;
- safer portrait spacing and typography for recent iPhones;
- no gameplay rule changes.
